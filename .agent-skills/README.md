## Quality gate

Curation beats volume: a small library of vetted skills keeps the agent's index
small and keeps shallow templates out of context.

| Gate | Threshold | Disable |
|---|---|---|
| Modules kept | 100 | `SKILLS_LIMIT=0` |
| Minimum body size | 1500 characters | `SKILLS_MIN_CHARS=0` |
| GitHub stars (OR) | 10 | `SKILLS_MIN_STARS=0` |
| Community votes (OR) | off | `SKILLS_MIN_VOTES=0` |
| Skills inspected | 5000 | `SKILLS_SCAN_LIMIT=0` |
| Per-folder quota | 20 in development, design, security, devops, product | `SKILLS_PER_CATEGORY` |
| Scan per folder | 1000 | `SKILLS_SCAN_PER_CATEGORY=0` |

Stars come from `/api/registry/<slug>` (one extra request per skill); votes come
from the listing card and cost nothing. Skills that fail a gate are recorded in
`.manifest.jsonl` with `"ok": false` and the reason, so a run is auditable.
